    연결

    폰 → GitHub → PC 봇
    이 앱은 주문을 직접 내지 않아요. 버튼을 누르면 레포의 control.json이 바뀌고, PC의 봇이 그걸 읽어 따릅니다. 아래 토큰은 이 기기에만 저장되고(PIN 암호화 가능) GitHub에만 전송돼요 (레포 하나의 파일 편집 권한뿐, 돈과는 무관). 바이낸스·업비트 키는 절대 여기 넣지 않습니다.
    🔒 토큰이 PIN으로 잠겨 있어요.
    아침 체크리스트
    1. 바이낸스 모의(Demo) API 키 → demo.binance.com → API Management → Create API → PC 문서\crypto_backtest\.env 에 BINANCE_API_KEY / BINANCE_API_SECRET (BOT_TESTNET=1, BOT_DEMO=1)
    2. GitHub 토큰 → 같은 .env 에 GITHUB_TOKEN, GITHUB_REPO=fafa2kk-stack/bit-office — 그리고 위 입력칸에도 같은 토큰
    3. PC에서 start_bot.bat 더블클릭 (창 켜둔 채) → 여기 "봇 연결됨"이 켜짐
    4. 여기서 ▶ 거래 시작 → 봇이 다음 판정(매일 09:03)부터 주문. 모의로 며칠 보고 BOT_TESTNET=0
