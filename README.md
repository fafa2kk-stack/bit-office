# 비트 오피스

픽셀 사무실의 직원 13명(시황팀 5 · 리서치 3 · 트레이딩 본부 3 · 리스크 위원 · 대표)이 백테스트로 검증된 규칙대로
비트코인 롱/현금/숏을 판정하고, 실제 일봉으로 모의 계좌를 굴리며, PC에서 도는 실제 봇을 원격 조종하는 웹앱.
폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있다.

- `index.html` — 앱 전체 (시세는 바이낸스 공개 API에서 읽기만, 주문은 내지 않음)
- `status.json` — PC 봇이 매 사이클 올리는 상태 → 앱의 "실제 봇" 탭
- `control.json` — 앱의 버튼이 바꾸는 원격 제어. PC 봇이 10분마다 읽는다
  - `trading`: `"on"` 이어야 주문을 낸다 (앱의 ▶ 거래 시작 / ⏸ 거래 중지)
  - `flatten`: `true` 면 전량 청산 후 trading off (앱의 ⛔ 전량 청산 후 중지, 일회성)
  - `kill`: `true` 면 봇이 아무것도 안 함 (비상 정지)
  - `venue`: `spot | futures | hybrid`, `short_size`: 0~1

앱의 버튼은 GitHub Fine-grained 토큰(이 레포 하나, Contents: Read and write)으로 `control.json` 을 고친다.
토큰은 폰에만 저장된다. 바이낸스 키는 이 레포 어디에도 없고 PC의 `.env` 에만 있다.
