# 비트 오피스

픽셀 사무실의 직원 5명이 백테스트로 검증된 규칙대로 비트코인 롱/현금/숏을 판정하고, 실제 일봉으로 모의 계좌를 굴리는 웹앱.
폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있다.

- `index.html` — 앱 전체 (시세는 바이낸스 공개 API에서 읽기만, 주문은 내지 않음)
- `status.json` — PC 봇이 매 사이클 올리는 상태 (앱의 "실제 봇" 패널)
- `control.json` — `"kill": true` 로 바꾸면 PC 봇이 다음 사이클부터 거래 중단 (원격 비상 정지)
